# 无字证明 · 竖屏（几何形变）

20–30 秒的竖屏短片，全程不说一句话，只靠几何形变（剪切、平移、旋转、拼合）证明一个定理。
画面是黑底方格纸、白线和一个强调色（黄），结论在音乐的收束重拍上弹出公式，片尾是「如果喜欢，请点个关注吧」和 @Vegavis。

**颜色**
- **底色：** 底 #07080A，上面铺极淡的方格纸（细格 40 px、粗格 200 px）和轻暗角。
- **常用色：** 白 #F3F5F7，灰 #878C93（标签、虚线）、#C9CCD1。
- **强调色：** 一部片只用一个，参考片是黄 #FFD52A（淡色 #FFF2B8）。其余全是白和灰。
- **后期：** 辉光 0.5，颗粒 0.05。

**动效语言**
1. **开场：** 第 0 帧就有内容。笔尖已经在描线（白核、强调色光晕、几粒火星），标题区先是 55 % 亮度，0.9 s 内亮满。
2. **描线：** 用笔尖把图形画出来（`G.path` 的 k 从 0 到 1）。填色随后约 0.8 s 淡入。面积标注 a²、b²、c² 用 0.45 s 从 1.4 倍缩到 1 倍弹出。
3. **形变：** 每一步都对齐到拍，用 S5 缓动。
   - 剪切时，不动的那条底边加粗发光，提示等底等高。
   - 滑动的边沿着灰色虚线滑轨走。
   - 移走的形状在原位留下灰色虚线轮廓。
4. **结论：** 目标形状的描边变成强调色，辉光缓慢呼吸。公式在收束重拍上用 0.55 s 从 1.22 倍缩到 1 倍弹出。
5. **尾声：**
   - 原来的形状和它变成的形状成对亮一下（sin² 包络，升降各 0.75 s）。
   - 然后片尾两行各用 0.6 s 淡入。
   - 最后 1.5 s 整个画面淡到黑。
6. **不闪屏：** 所有明暗变化不短于 0.4 s，`flash_check.py` 必须报告 0 次。

**节奏与音乐**
- **按拍对齐：** 所有提示点都写成拍号，`beat(n) = n × 60/BPM`。结论落在乐句收束的重拍上，之后进入尾声段，做成对亮起和片尾。
- **参考片的剪法：**
  - 配乐取自《几何之美 · 二》，95 BPM，从原曲 229.4152 s（原曲第 363 拍）剪 27.7895 s。
  - 片中第 0–31 拍是高潮，第 32 拍是收束重拍（结论），第 33–44 拍是尾声。
  - 原曲文件不在仓库里。
- **剪辑命令：**
  ```bash
  ffmpeg -ss <起点秒> -i <原曲> -t <END> -af "afade=t=in:st=0:d=0.03,afade=t=out:st=<END-1.5>:d=1.5" -c:a aac -b:a 256k audio/music.m4a
  ```
  音频原样混流，不调增益、不做响度归一。

**规则**
- **画面里的字：** 只有标题区、结论公式和片尾两行。没有解说、字幕、进度条和读数栏。
- **数学自检：** 每一帧都要对，在 `proof.js` 里写 `window.CHECK.run()`。参考片检查两块面积在 834 帧里一直是 9 和 16，最后正好拼成 5 × 5。
- **确定性：** 画面是 t 的纯函数，`--det` 必须通过。

**可以接着做的题**（都适合几何形变）
- 平方差 (a + b)(a − b) = a² − b²；
- 完全平方 (a + b)² = a² + 2ab + b²；
- 1 + 3 + 5 + … + (2n − 1) = n²；
- 三角形内角和；
- 三角形面积 = 底 × 高 ÷ 2（平行四边形剪切）；
- 梯形面积；
- 圆面积（圆环展开成三角形）。
