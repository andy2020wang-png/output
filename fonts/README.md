# 字体

引擎使用的字体全部来自 Google Fonts，均为开源授权，随仓库一同分发，许可证见 `licenses/`：

- SIL Open Font License 1.1：除下列两种外的全部字体（Noto Serif SC、Noto Sans SC、马善政、志莽行书、龙藏、站酷小薇、霞鹜文楷 TC、Noto 象形/楔形/腓尼基文字、Cinzel、EB Garamond 等）
- Apache License 2.0：Smokum、Special Elite

`local.css` 把字体族名映射到本目录的文件；`list.tsv` 记录了每个文件的来源地址，`fetch.sh` 可按该列表重新下载。
