# 字幕稿（定稿）

规范：书面语、完整句，不用口语和缩略句；每张字幕卡最多两行，每行不超过 18 字（汉字与全角标点计 1，数字与字母计 0.5）；`/` 表示换行。
已按四个视角的审校意见修改：古代史实、近现代史实、中文编辑、抖音观众。

## 开场
- 系列标签：科技树 01 · 记录
- 问题：若要给一万年后的人留下“我在这里”， / 应当把它写在哪里？
- 选项：A 压印在泥板上　B 写在纸上　C 存入硬盘　D 上传至云端
- 倒数：3 · 2 · 1
- 揭晓：人类的记录史揭示了一个反直觉的规律： / 记录方式越先进，往往越难长久保存。
- 选项下方依次显示：A 已保存 5,000+ 年｜B 已保存 2,000+ 年｜C 预计 2～5 年｜D ？
- 片名：人类如何记录信息 / 从结绳到云端的科技树

## 第一章 结绳
- 年代：中国上古传说 · 安第斯地区 约公元 600 年起
- 标题：结绳　英文：Knotted cords · Khipu
- 字幕：
  1. 《周易・系辞下》载：“上古结绳而治， / 后世圣人易之以书契。”
  2. 印加帝国以绳结按十进制记数， / 绳结的位置分别表示个、十、百、千位。
  3. 已知存世的安第斯结绳近一千四百件， / 它们是否记录语言信息，至今仍无定论。
  4. 绳索会腐烂，解读结绳的人也会逝去。 / 要让记录长久保存，载体必须更加坚固。
- 计数器：已知最早的结绳实物 已保存 1,000+ 年

## 第二章 泥板
- 年代：约公元前 3300 年 · 美索不达米亚 · 乌鲁克
- 标题：泥板　英文：Cuneiform on clay
- 字幕：
  1. 最早的符号是用尖头芦苇刻画的图形， / 后来改用斜削的芦苇压出楔形笔画。
  2. 最早的泥板大多是行政账目， / 记录粮食、牲畜等物资的收支。
  3. 公元前 612 年，亚述都城尼尼微陷落。 / 据信大火反而烧硬了图书馆的部分泥板。
  4. 这座亚述巴尼拔图书馆的泥板及残片， / 如今有三万余件藏于大英博物馆。
- 计数器：有字泥板 已保存 5,000+ 年

## 第三章 莎草纸
- 年代：约公元前 3000 年起 · 古埃及
- 标题：莎草纸　英文：Papyrus · The Diary of Merer
- 字幕：
  1. 埃及人把纸莎草的茎剖成薄条， / 纵横叠压，捶打晒干，制成书写材料。
  2. 莎草纸轻便，可制成长卷， / 但不耐潮湿，存世者多出自干燥的埃及。
  3. 《梅勒日志》是最早的有字莎草纸之一， / 记录了为胡夫金字塔运送石灰石的经过。
- 计数器：有字莎草纸 已保存 4,500+ 年

## 第四章 龟甲
- 年代：约公元前 1250 年 · 商 · 殷墟
- 标题：龟甲　英文：Oracle bones
- 字幕：
  1. 商代的占卜者灼烧龟甲与牛骨， / 依据裂纹判断吉凶。
  2. 刻在甲骨上的卜辞称为甲骨文， / 是中国已知最早的成体系文字。
  3. “卜”字的字形， / 描摹的正是龟甲上灼出的裂纹。
  4. 迄今出土的刻辞甲骨超过十六万片， / 单字约四千五百个，约三分之一已释读。
- 计数器：刻辞甲骨 已保存 3,200+ 年

## 第五章 竹简
- 年代：商代已有简册 · 现存实物始于战国早期
- 标题：竹简　英文：Bamboo slips
- 字幕：
  1. 竹片削平、烘干后，以毛笔逐字书写， / 再以编绳连缀成卷。
  2. “册”字的字形， / 描摹的正是以编绳串联的一排竹简。
  3. 西汉东方朔初到长安上书， / 共用木质奏牍三千枚。　〔屏幕小字：见《史记・滑稽列传》褚少孙补记〕
  4. 两人合力方能举起， / 汉武帝用了两个月才读完。
- 计数器：曾侯乙墓竹简 已保存 2,400+ 年

## 第六章 造纸
- 年代：公元 105 年 · 东汉
- 标题：造纸　英文：Paper
- 字幕：
  1. 《后汉书・蔡伦传》记载： / “缣贵而简重，并不便于人。”
  2. 蔡伦以树皮、麻头、破布、渔网为原料， / 改进造纸术，此后“天下咸称蔡侯纸”。
  3. 出土的西汉古纸表明，蔡伦之前已有纸； / 蔡伦的改进，使纸逐渐取代了简帛。
  4. 造纸术逐步向西传播， / 最迟于 12 世纪中叶传入欧洲。
- 计数器：西汉古纸 已保存 2,000+ 年

## 第七章 印刷术
- 年代：868—1455 年 · 唐 · 北宋 · 美因茨
- 标题：印刷术　英文：Printing
- 字幕：
  1. 雕版印刷将整页文字反刻于木板， / 经刷墨、覆纸、擦刷，即可印成一页。
  2. 敦煌出土的《金刚经》印于 868 年， / 是现存最早有明确纪年的印刷书籍。
  3. 北宋庆历年间，毕昇以胶泥刻制活字， / 排版印刷后拆下，活字可以重复使用。
  4. 这项发明记载于沈括的《梦溪笔谈》， / 但毕昇的泥活字没有实物传世。
  5. 约 1455 年，古腾堡在美因茨 / 用金属活字印出了《圣经》。
  6. 至 1500 年，欧洲印本迅速增加， / 存世至今的仍有约三万种。
- 计数器：《金刚经》已保存 1,150+ 年

## 第八章 打孔卡
- 年代：1890 年 · 美国人口普查
- 标题：打孔卡　英文：Punched card
- 字幕：
  1. 1804 年，雅卡尔提花机以串联的打孔卡 / 控制织物的花纹。
  2. 1890 年，美国人口普查改用打孔卡， / 由机器代替人工读取和统计。
  3. 前一次普查的统计历时七年以上； / 此次六个月完成计数，两年完成整理。
  4. 制表机公司后来与其他公司合并， / 新公司于 1924 年更名为 IBM。
  5. 1921 年，华盛顿的一场火灾 / 让这次普查的原始表格大量受损。
  6. 残存表格于 1930 年代经国会批准销毁， / 普通人口调查表仅存六千余人的记录。
- 计数器：普通人口调查表 仅存 6,160+ 人的记录

## 第九章 磁带
- 年代：1951 年 · UNIVAC I
- 标题：磁带　英文：Magnetic tape
- 字幕：
  1. 磁带以磁性涂层的磁化方向记录信息， / 人眼无法直接读取，只能依靠机器。
  2. 1951 年，UNIVAC I 计算机 / 配备了首款商用计算机磁带机。
  3. 时至今日，部分大型云服务商 / 仍以磁带归档极少读取的冷数据。
  4. 最新一代 LTO 磁带每盒可存储 40 TB， / 厂商标称在适宜条件下可保存三十年。
  5. 从这里开始，计数器显示的是预计寿命， / 它们尚未经过时间的检验。
- 计数器：数据寿命（厂商标称） 30 年

## 第十章 软盘
- 年代：1971 年起 · IBM 8 英寸软盘
- 标题：软盘　英文：Floppy disk
- 字幕：
  1. 大众熟悉的 3.5 英寸软盘， / 容量只有 1.44 MB。
  2. 它通常装不下今天手机拍摄的一张照片， / 许多软件的“保存”图标却仍是软盘。
  3. 如今，大多数计算机已不再配备软驱； / 盘片即使完好，数据也难以读取。
  4. 日本法规中最后一项软盘使用要求， / 直至 2024 年 6 月才被废除。
- 计数器：数据寿命（估计） 5～15 年

## 第十一章 硬盘
- 年代：1956 年发明 · 1980 年缩小到 5.25 英寸
- 标题：硬盘　英文：Hard disk drive
- 字幕：
  1. 硬盘的问世，比软盘还早十五年： / 1956 年，IBM 推出了第一台硬盘。
  2. 它重约一吨， / 却仅能存储约五百万个字符。
  3. 首款 5.25 英寸硬盘的容量仅有 5 MB， / 如今单块硬盘的容量已超过 40 TB。
  4. 容量增长了数百万倍， / 保存寿命却估计只有二至五年。
- 计数器：数据寿命（估计） 2～5 年

## 第十二章 云
- 年代：2006 年起 · 数据中心
- 标题：云　英文：The cloud
- 字幕：
  1. 2006 年，亚马逊推出 S3 云存储服务， / 数据开始大规模存放于远程数据中心。
  2. 云端的本质，仍是硬盘、闪存和磁带， / 需要有人持续供电、维护并迁移数据。
  3. 据报道，Myspace 在一次服务器迁移中 / 丢失了约五千万首用户上传的歌曲。
  4. 皮尤研究中心发现：2013 年的网页， / 十年后约有 38% 已无法访问。
  5. 2015 年，互联网先驱温顿・瑟夫警告： / 我们的时代可能成为“数字黑暗时代”。
- 计数器：数据寿命 ？ 取决于是否有人持续维护

## 结尾
1. 记录越来越快、越来越多， / 却也越来越依赖机器与持续的维护。
2. 回到开头的问题： / 最经得起时间检验的答案，是 A：泥板。
3. 而云端能保存多久， / 取决于是否一直有人维护它。
4. 过去，记录往往比记录它的人活得更久； / 如今，人可能比自己的记录活得更久。
5. 你手机中的照片，三十年后仍能打开吗？
6. 这段视频本身也是一份记录： / 它的声音里写着“我在这里”四个字。
7. 片尾卡：人类如何记录信息 / 科技树 01 · 记录 / 下一集：人类如何计算 / 本片画面与声音均由代码生成

## 篇章之间的转场

每一次转场都借用"下一种载体"的物理动作，同时切换配色、字体和配乐乐器；时长约 1 秒，并配一个同调的过渡音。

| 从 → 到 | 转场 | 画面 | 声音 |
|---|---|---|---|
| 开场 → 结绳 | 线变绳 | 展签上的一道朱红细线垂落，变成一根绳子，织物纹理自上而下铺满画面 | 绳子拉紧的摩擦声 |
| 结绳 → 泥板 | 压印 | 绳结压进湿泥，以压痕为中心向外推开泥面 | 湿泥的闷响 |
| 泥板 → 莎草纸 | 烧穿 | 尼尼微的火光蔓延，烧穿画面，露出莎草纸 | 火焰轰鸣转为竖琴 |
| 莎草纸 → 龟甲 | 灼裂 | 炽热的裂纹从一点蔓延，裂缝中露出龟甲 | 骨裂脆响 |
| 龟甲 → 竹简 | 竹片落位 | 竹简一根接一根自上而下落位，覆盖画面 | 竹片碰撞声 |
| 竹简 → 造纸 | 墨晕 | 墨迹在纸上洇开，吞没竹简 | 水滴与古筝刮奏 |
| 造纸 → 印刷术 | 拓印 | 刷了墨的雕版覆在纸上，揭起后露出印好的页面 | 揭纸声 |
| 印刷术内部 | 唐 → 宋 → 美因茨 | 雕版碎成方块，变成一枚枚活字；活字被压印机压下，出现哥特体书页 | 陶字碰撞、压印机重击 |
| 印刷术 → 打孔卡 | 冲孔 | 版面上冲出一排排长方形孔洞，孔中露出蓝图 | 冲孔声 |
| 打孔卡 → 磁带 | 卷入 | 卡片横向滑入，被卷进磁带盘 | 走带声 |
| 磁带 → 软盘 | 像素化 | 磁带盘转动着变成低分辨率像素，进入 DOS 画面 | 芯片音乐起音 |
| 软盘 → 硬盘 | CRT 关机 | 显示器画面收缩成一条亮线后熄灭，硬盘盘片从黑暗中亮起 | 关机"嘀"声与盘片启动声 |
| 硬盘 → 云 | 拉远 | 镜头从盘片拉远，盘片变成机柜里的一格，机柜排成数据中心 | 风扇底噪渐起 |
| 云 → 结尾 | 熄灯 | 机柜指示灯一盏盏熄灭，画面回到开场的纸面 | 所有声音抽空，只剩一声钟 |
